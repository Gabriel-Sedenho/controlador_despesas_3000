# Controlador Despesas 3000

Sistema em Python para controle e gerenciamento de despesas pessoais, organizado com arquitetura em camadas (Model-View) e persistência em banco de dados relacional.

---

## Funcionalidades

- **Autenticação de Usuários:** Cadastro e login de usuários com gerenciamento de sessão.
- **Gestão de Categorias:** Criação e visualização de categorias personalizadas para organizar os gastos.
- **Controle de Despesas:**
  - Registro de novas despesas vinculadas a usuários e categorias.
  - Consulta geral de despesas cadastradas.
  - Filtragem e visualização de despesas por categoria.
